解析の考え方

MetroPro バイナリー DAT (format 1–3) の高さと Intensity を読み取ります。高さの単位は nm、横方向は µm です。DATX・ASCII DAT には対応していません。ファイルはサーバーへ送信されません。

表面・形状

有効点を使って最小二乗平面を求め、必要に応じて除去します。クリップは高さ・断面・微分に適用されます。PSD / FFTへの適用は「マップと同じ補正後」を選んだ場合だけです。粗さ指標はクリップ前の値から計算します。3D は表示だけを間引き、欠損点を 0 高さとして描きません。

元コード互換 PSD

元の Python と同じ P(k) = (2πd/N)|FFT(z)ₖ|²、fₖ = k/(Nd) を使用。DC と Nyquist を除外し、欠損点を 0 で埋めます。窓関数・ライン平均除去は使いません。標準の片側 PSD 密度とは正規化が異なります。

標準 PSD

各ラインの平均を除去した後、矩形または周期的 Hann 窓で FFT。P(k) = d|FFT(w·z)ₖ|² / Σw² を片側に倍化します（Nyquist は倍化しません）。DC は表示から除外します。欠損ラインの除外、または線形補間を選択できます。端点の補間は最近傍値を用います。

単位と注意点

両モードとも横軸を cycles/µm で表すため、PSD の次元は nm²·µm です。元コード・PDF の「nm³」表記は、nm と µm が混在する計算値と整合しません。PDF の f = k/((N−1)d) は FFT の周波数グリッドと異なるため、Python の k/(Nd) を採用しています。

元コード互換の微分は nm/pixel、絶対値が 10 を超える値を 0 に置換します。標準モードは実際の間隔で割った nm/µm。Intensity は little endian の最初のフレームを使い、高さマップと同じ上下方向に揃えます。

形状補正とFFT

球面・円筒は低サグの2次近似、一般2次曲面は1,x,y,x²,xy,y²をフィットします。FFTのGaussian低域通過は exp(−ln2·(f/fc)²)、高域通過はその補数、帯域通過は両者の積です。急峻フィルターはリンギングを生じます。MetroProの主要な機能構成を参考にした独立実装であり、同ソフトとの完全一致を保証するものではありません。

2D FFTを読む

周波数ベクトルの角度はX軸基準・反時計回り。筋の向きはこのベクトルに対して90°です。実数表面のスペクトルは原点対称なので、両側ピークは同じ周期を表します。方向性指標はΣP cos2θ, ΣP sin2θから計算した0〜1の角度集中度です。0に近くても複数方向が打ち消し合っている場合があり、マップと合わせて判断してください。

PlotLauncher Webへ

PNGの右横のXLSXは先頭の「Plot Data」シート・ヘッダー1行で読み込み、GeneralまたはAFM断面でX/Y列を指定してください。複数断面は距離・高さの列を2列ずつ追加します。PSDは対数軸を選択します。PNGの軸範囲はXLSXの数値を切り詰めません。
